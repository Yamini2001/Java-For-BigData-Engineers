## 🚀 Getting Started

### Prerequisites

- **Java Development Kit (JDK):** Version 17 or higher.
- **IDE:** Eclipse IDE for Java Developers.
- **Git:** For cloning the repository and tracking changes.

### Clone the Repository

Replace the URL below with your actual GitHub repository URL.

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY-NAME.git
```

### Import into Eclipse

1. Open Eclipse IDE.
2. Select **File → Import**.
3. Choose **General → Projects from Folder or Archive** (or **Existing Projects into Workspace**, depending on your Eclipse version).
4. Select the cloned project folder.
5. Click **Finish**.

### Run a Java Program

1. Expand the project in Eclipse's Package Explorer.
2. Open the `src` folder.
3. Navigate to the appropriate package.
4. Open the Java file you want to execute.
5. Click **Run** or press `Ctrl + F11`.
