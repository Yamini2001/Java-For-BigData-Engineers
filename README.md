# Java Core & Big Data Engineering Lab Assignments 🐘☕

A curated repository of Java implementations, algorithmic exercises, and data-processing logic developed using **Eclipse IDE** to build strong foundations for Big Data pipelines, distributed frameworks, and software development.

---

## 📂 Repository Structure & Included Programs

All programs are structured inside the `JavaAssignment1` project under the `MyFirstProject` package:

| Program File Name | Key Concepts / Description |
| :--- | :--- |
| 📄 `AreaCircle.java` | Calculates the area of a circle using radius inputs and mathematical constants. |
| 📄 `ArithmeticOperations.java` | Implements basic arithmetic logic (addition, subtraction, multiplication, division). |
| 📄 `EvenOdd.java` | Evaluates whether an integer input is even or odd using modulo operations. |
| 📄 `LargestTwoNumbers.java` | Identifies the larger value between two given inputs using conditional statements. |
| 📄 `PositiveNegativeValue.java` | Checks if a user-supplied number is positive, negative, or zero. |
| 📄 `SimpleInterest.java` | Computes simple interest using Principal, Rate, and Time variables. |
| 📄 `StudentResult.java` | Determines student evaluation outcomes (`Pass`/`Fail`) based on mark thresholds. |
| 📄 `TemperatureConversion.java` | Performs conversion between Celsius and Fahrenheit temperature scales. |
| 📄 `TotalAverageMarks.java` | Calculates total score sum and average grade across multiple subjects. |
| 📄 `VotingEligibility.java` | Validates voter eligibility using age comparison expressions. |
---

🛠️ Concepts & Operations Covered

User Input Handling: Reading standard inputs (float, int, String) dynamically using java.util.Scanner.

Arithmetic & Logic Processing: Execution of numeric calculations and floating-point precision operations.

IDE & Module Management: Setting up non-modular Java applications cleanly within Eclipse.

🚀 Getting Started

Prerequisites

Java Development Kit (JDK): Version 17 or higher.

Eclipse IDE: Eclipse IDE for Java Developers.

Running the Code in Eclipse IDE

Clone the Repository:

git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY-NAME.git


Import into Eclipse:

Open Eclipse IDE.

Select File > Open Projects from File System...

Click Directory..., select the project folder (JavaAssignment1), and click Finish.

Execute a File:

Open the desired .java file inside the src package (e.g., ArithmeticOperations.java).

Press Ctrl + F11 or click the green Play (▶) button in the toolbar to run.
